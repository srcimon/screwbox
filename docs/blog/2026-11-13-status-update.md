Hello my dear friends,

I haven't posted an update since August, so I wanted to drop a quick note to let you know I'm still here!

While I haven't released any game-changing features for ScrewBox lately, I've been steadily rolling out lots of small, incremental improvements that are really starting to add up.
Across ten new versions since my last post, I've introduced significant performance boosts alongside a bunch of new tools—including entity baking, texture lines, fixed-length ropes, mumble audio voices, and a new pixel font.

The biggest highlight, though, is how lighting works in orthographic scenes.
Thanks to much better color blending, colored lights are finally a viable option.
The latest update also fixes some pretty ugly glitches with how indirect light interacts with orthographic walls.

I put together a short [showcase on YouTube](https://youtu.be/_lI_ZcGKvhI) so you can see the dynamic lighting and real-time smoke effects in action.

If it's been quiet on the blog, it's only because I've been heads-down coding new features and polishing old ones in ScrewBox!
